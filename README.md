# Инструкция по запуску AdminCore Bot

## 1. Создание бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather)
2. Напиши `/newbot`
3. Придумай имя и username бота
4. Скопируй токен (выглядит примерно так: `1234567890:AAH...`)

⚠️ Токен — это как пароль от бота. Никому его не показывай и не публикуй (в том числе в чатах, скриншотах, репозиториях на GitHub).

## 2. Подготовка файлов

Помести в одну папку три файла:
- `bot.py` — код бота
- `requirements.txt` — список зависимостей

## 3. Установка зависимостей

Открой терминал, перейди в папку с ботом:

```
cd путь\до\папки\с\ботом
```

Установи зависимости одной командой:

```
pip install -r requirements.txt
```

Если команда `pip` не находится — попробуй `python -m pip install -r requirements.txt` или `py -m pip install -r requirements.txt`.

## 4. Вставка токена

1. Открой `bot.py` любым текстовым редактором
2. Найди строку:
   ```python
   TOKEN = "ВСТАВЬ_СВОЙ_НОВЫЙ_ТОКЕН"
   ```
3. Вставь свой токен вместо `ВСТАВЬ_СВОЙ_НОВЫЙ_ТОКЕН`, не убирая кавычки
4. Сохрани файл

## 5. Запуск бота

В том же терминале (в папке с ботом):

```
python bot.py
```

Если команда `python` не находится — попробуй `py bot.py`.

Если всё хорошо — в терминале появится:
```
Админ-бот запущен
Start polling
Run polling for bot @имя_бота ...
```

Терминал должен оставаться открытым, пока бот работает. Закрытие окна = остановка бота (остановить также можно через `Ctrl+C`).

## 6. Добавление бота в группу

1. Открой или создай группу в Telegram
2. Добавь туда бота
3. Сделай его администратором
4. Обязательно выдай права:
   - **Блокировка пользователей** (Ban users)
   - **Ограничение пользователей** (Restrict members) — нужно для `/mute` и `/unmute`

## 7. Команды бота

Все команды доступны только администраторам группы.

| Команда | Как использовать | Что делает |
|---|---|---|
| `/ban` | Ответом (reply) на сообщение пользователя | Банит пользователя |
| `/unban <ID>` | С указанием ID или reply | Разбанивает пользователя |
| `/mute [минуты]` | Ответом на сообщение, минуты — опционально | Мутит пользователя (без минут — навсегда) |
| `/unmute` | Ответом на сообщение | Снимает мут |
| `/stats` | Без аргументов | Показывает число известных боту пользователей чата |
| `/ext` | Без аргументов | Показывает предупреждение перед массовым баном |
| `/ext confirm` | — | Банит ВСЕХ известных боту пользователей чата, кроме админов |

⚠️ `/ext confirm` — необратимое массовое действие. Используй только на своём чате и только когда точно уверен.

## 8. Частые проблемы

- **Бот не отвечает на команды в группе** — проверь, что бот админ и что у него есть нужные права (шаг 6).
- **`ModuleNotFoundError: No module named 'aiogram'`** — не выполнен шаг 3, установи зависимости.
- **Бот запускается, но `/ban` пишет "Недостаточно прав"** — команду пишет не администратор группы, либо бот не видит, что ты админ (перезайди в группу или подожди — Telegram иногда кеширует список админов).
- **`TelegramConflictError` при запуске** — где-то уже запущен ещё один экземпляр этого же бота (например, на другом компьютере или в другом окне терминала). Останови лишний процесс.
